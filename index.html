Debug — proprietary channel probe

Throwaway diagnostic. Tests whether the proprietary WHOOP service is reachable at all — not real functionality.


  


  
Debug — CLIENT_HELLO handshake

  

    
Throwaway diagnostic. Sends WHOOP's static CLIENT_HELLO frame and logs every notification received afterward, decoded where possible.

    
    

  


  
Debug — battery level query

  

    
Throwaway diagnostic. Does the full handshake, then sends GET_BATTERY_LEVEL — the first real custom command, not just the static hello.

    
    

  


  
Debug — firmware version query

  

    
Throwaway diagnostic. Sends REPORT_VERSION_INFO and decodes the firmware version fields.

    
    

  


  
Debug — historical data offload

  

    
Throwaway diagnostic. Drives the real offload state machine (GET_DATA_RANGE → SEND_HISTORICAL_DATA → chunks → ACK each HISTORY_END → stop at HISTORY_COMPLETE) and captures raw chunk bytes for later decoding. May take a while — leave it open.
